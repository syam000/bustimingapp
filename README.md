# SG Bus Timing

A tiny, dependency-free web app that shows live bus arrival timings for
Singapore bus stops, powered by the [LTA DataMall](https://datamall.lta.gov.sg/)
open APIs. Built to run locally — nothing to deploy.

## Features

- Search bus stops by code, road name, or place.
- Watch multiple stops at once (saved in your browser's `localStorage`).
- Live-ish view of the next 3 buses per service, auto-refreshing every 15s.
- Works fully offline out of the box using built-in **mock data**, so you
  can try it immediately without an API key.
- Switches to **real live data** automatically once you add a free LTA
  DataMall API key.

## Quick start (offline mock mode)

No API key needed.

```bash
npm start
```

Open http://localhost:3000 — search for a stop (try `83139`, `Orchard`,
`Interchange`, or any 5-digit code from `lib/busStopsSample.js`) and add it
to your watched stops.

## Using real live data

1. Get a free key: https://datamall.lta.gov.sg/content/datamall/en/request-for-api.html
2. Copy `.env.example` to `.env` and set `LTA_ACCOUNT_KEY=<your key>`.
3. (Optional but recommended) Fetch the full ~5,000-stop list so search
   covers all of Singapore, not just the small bundled sample:
   ```bash
   npm run fetch-stops
   ```
   This caches results to `data/bus-stops.json`, which the server prefers
   automatically when present.
4. Start the app:
   ```bash
   npm start
   ```
   The header badge will show **LIVE DATA** and arrival times will come
   straight from LTA DataMall's `v3/BusArrival` endpoint.

You can force mock mode at any time (even with a key configured) by running:

```bash
npm run mock
```

## How it works

- `server.js` — a small built-in `http` server (no Express, no build step).
  Serves the static frontend from `public/` and exposes three JSON routes:
  - `GET /api/config` — reports whether the server is in `live` or `mock` mode.
  - `GET /api/stops?q=` — searches bus stops (from `data/bus-stops.json` if
    present, otherwise a small bundled sample).
  - `GET /api/arrivals?stop=` — returns bus arrival timings, either
    proxied live from LTA DataMall or generated by the offline mock.
- `lib/ltaClient.js` — thin fetch wrapper around the real LTA DataMall API.
- `lib/mock.js` — deterministic, slowly-ticking fake arrival data shaped
  exactly like the real `v3/BusArrival` response, so the frontend code
  doesn't need to care which mode is active.
- `public/` — plain HTML/CSS/JS frontend, no framework, no build tools.
- `scripts/fetch-stops.js` — one-off script to cache the full bus stop
  list locally (requires an API key).

## Tests

```bash
npm test
```

Runs Node's built-in test runner against the mock data generator and
bundled bus stop sample.

## Notes

- This is intentionally simple and meant for local use/testing only —
  there's no build step, bundler, or deployment config.
- The server adds a short (8s) in-memory cache per stop code to avoid
  hammering the LTA API when multiple tabs are open.
- `.env` is git-ignored; never commit your real API key.
